Setup

One-time setup.
Works forever after.

1

Download both files

Download SimplyClip_Extension.zip (the extension) and SimplyClip_Helper.exe (processes downloads). Save both somewhere easy to find.

2

Extract the zip

Right-click SimplyClip_Extension.zip → Extract All. Keep this folder permanently — Chrome needs it.

3

Load into Chrome

Go to chrome://extensions. Toggle Developer mode on, click Load unpacked, select the extracted folder.

4

Run the helper — you're done

Double-click SimplyClip_Helper.exe. Windows may warn you — click "More info" then "Run anyway". The ✂ Clip button will appear on YouTube. The helper starts automatically every time you boot.
